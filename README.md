# 🛡️ Retail Asset Protection & Shrink Optimization Engine

An end-to-end data analytics pipeline and interactive executive dashboard designed to evaluate high-risk retail asset protection strategies, measure shrink reduction, and balance customer sales friction.

## 📋 Project Overview
Asset protection analytics requires balancing two competing forces: **protecting high-risk inventory (shrink reduction)** versus **maintaining a frictionless customer shopping experience (sales preservation)**. 

This project simulates a multi-store retail environment, ingests relational data, runs SQL analytics via DuckDB, and powers an interactive Streamlit dashboard to guide strategic decision-making on locked-item merchandising.

## 🛠️ Tech Stack
* **Language:** Python (`pandas`, `numpy`, `duckdb`)
* **Data Warehousing / SQL:** DuckDB (local SQL execution mimicking enterprise data platforms like Databricks/Snowflake)
* **Dashboard & Visualization:** Streamlit
* **Version Control:** Git & GitHub
